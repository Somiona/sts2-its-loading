「不再乾等 · It's Loading」

修復了塔2開 mod 沒有進度條的「bug」。
QQ群 1087829235

裝了一堆 mod 之後,每次啟動遊戲都要對著黑畫面乾等十幾秒到半分鐘,不知道是當機了還是在載入,只能乾瞪眼。

這個 mod 在遊戲啟動過程中會顯示進度條,並且告訴你現在到底在幹嘛:

    正在讀取創意工坊訂閱(第幾個 / 共幾個)
    正在載入哪個模組、花了多少毫秒
    遊戲啟動到哪一步(圖集 / 本地化 / 模型資料庫 / 資源預載……)

『主題切換』

提供了多個主題，可以在模組設定中更改，重啟遊戲生效

『瀑布圖』

可以方便地查看啟動階段每個模組的載入時間，並提供 API 讓其他 mod 讀取資料

『注意』

第一次啟動看不到預載階段的進度條,首次啟動時會完成一次啟動畫面注入(左上角會有提示),從下一次啟動起進度條全程可見。
由於 Godot 引擎限制,進度條一些位置會卡住,通常 3-5 秒左右之後進度條會正常滾動。

> public-beta 版已支援:由原生渲染繪製載入畫面,解決 Godot 引擎啟動期的渲染限制
> (設定裡「(Beta) Native loading screen renderer」可關閉)

由於更新了檔案結構,更新後第一次啟動遊戲可能出現畫面錯誤,重啟即恢復正常


『如何解除安裝』

在遊戲內 mod 選單關閉、退訂,或直接刪掉 mod 資料夾都可以。啟動時偵測到 mod 已關閉或移除,會自動清理注入的啟動畫面。
